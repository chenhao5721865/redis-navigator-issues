# Redis Navigator — Issues & Feedback

  This repository is the official issue tracker for the **Redis Navigator** plugin for IntelliJ IDEA / JetBrains IDEs.

  - Plugin page: https://plugins.jetbrains.com/plugin/34398-redis-navigator

  ## Report a bug

  Please open an [issue](https://github.com/chenhao5721865/redis-navigator-issues/issues/new) and include:

  1. Plugin version and IDE version (**Help → About**)
  2. Redis server type and version (e.g. Redis 7.2, Memurai, AWS ElastiCache)
  3. Connection type: direct / TLS / self-signed
  4. Steps to reproduce, expected vs. actual result

  > ⚠️ Never post passwords, hostnames, or key contents that are sensitive.

  ## Feature requests

  Feature requests are welcome — please describe your use case, not just the feature.

  ## FAQ

  **Q: The plugin doesn't appear in my IDE.**
  
  A: Redis Navigator supports IntelliJ IDEA (Community & Ultimate), PyCharm, WebStorm, GoLand, PhpStorm, RubyMine,
  DataGrip and Rider (builds 253–262).
